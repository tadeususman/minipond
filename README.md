# Mini Pond

A virtual koi pond for stress relief. Single-file web app: open `index.html` in a browser.

- Top-down pond drawn with Canvas 2D (koi, lily pads, ripples, light on the water)
- "Dive in" underwater view with Three.js (loaded from CDN on demand)
- Ambient fountain sound via Web Audio (mp3 embedded as base64 in the HTML)
- Tap to feed, sweep to scatter the koi, drag lily pads; state is kept in localStorage
